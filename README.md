# MediCompanion AI - Download

Welcome to the official release repository for **MediCompanion AI**! 

This repository is dedicated to providing easy access to the latest APK files for testing and distribution.

## 📱 Download Latest Version

### Option 1: GitHub Releases (Recommended)

Download the latest version from our [Releases page](https://github.com/naimhakimi-sketch/MediCompanion-AI-Release/releases).

1. Visit the [Releases page](https://github.com/naimhakimi-sketch/MediCompanion-AI-Release/releases)
2. Click on the latest release
3. Download the APK file from the "Assets" section
4. Install on your Android device

### Option 2: Direct Download

Browse the [`releases/`](./releases) folder to download APK files directly.

## 🚀 Installation Instructions

1. **Download the APK file** using one of the methods above
2. **Enable Unknown Sources** on your Android device:
   - Go to Settings → Security (or Apps & notifications)
   - Enable "Install unknown apps" or "Unknown sources"
   - Select your file manager or browser to allow installations
3. **Open the downloaded APK file** and tap "Install"
4. **Launch the app** and enjoy MediCompanion AI!
